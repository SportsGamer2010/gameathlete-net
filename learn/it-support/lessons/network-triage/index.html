Lesson 2 · ~30 min

Network Connectivity Triage

Diagnose why one PC cannot reach game servers.

Game scenario: PC-07 connected locally but cannot join online matches.

Steps

  1. Gather symptoms

    Log error message, IP (ipconfig), ping gateway, ping 8.8.8.8.

  2. Isolate layers

    Test physical → IP → DNS → firewall. Document each elimination.

  3. Apply fix

    Renew DHCP, flush DNS, or swap port. Record commands.

  4. Verify

    Confirm game connects. Note resolution time.

Your goal

Triage report

Symptoms, tests, fix, time.

Format: Doc

Success criteria

Check each item when your deliverable meets the standard.

  • ping
