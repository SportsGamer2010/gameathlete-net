Lesson 1 · ~25 min

Map Cloud Services

Choose IaaS/PaaS/SaaS for league needs.

Game scenario: Site hosting, graphic CDN, backup storage.

Steps

  1. Categorize needs

    Static site = PaaS (Pages/Netlify). Assets = object storage (S3/R2).

  2. Compare free tiers

    GitHub Pages vs Cloudflare Pages vs Vercel—pick one.

  3. Draw architecture

    User → CDN → static site; Assets → bucket → CDN.

  4. Cost note

    Estimate $0/month on free tier for <10GB traffic.
