Networking

TCP/IP, routing, switching, and network troubleshooting for real environments.

beginner10–14 weeks

Overview

Build the networking skills used in schools, businesses, and field service—subnetting, VLANs, DHCP/DNS, and structured troubleshooting.

What You'll Learn

  • TCP/IP
  • Subnetting
  • Routing & switching basics
  • DHCP & DNS
  • Network troubleshooting
  • Documentation

What You'll Build

  • Network troubleshooting work order
  • Small office network design lab
  • Network documentation project

Tools You'll Use

  • Wireshark
  • Cisco Packet Tracer
  • Windows
  • Linux
  • ping & traceroute

Certifications You Can Work Toward

GameAthlete provides training preparation. Third-party certifications are awarded by their issuing organizations—not by GameAthlete.

  • CompTIA Network+
  • Cisco CCST
  • Cisco CCNA (progression)

Career Outcomes

Prepare for opportunities—GameAthlete does not guarantee employment.

  • Network Technician
  • NOC Technician
  • Field Network Technician
  • Junior Network Administrator

Experience Opportunities

  • Network labs
  • GameAthlete Works network projects
  • Field-service style simulations

Prerequisites

  • IT Support fundamentals recommended
  • Logical problem-solving
