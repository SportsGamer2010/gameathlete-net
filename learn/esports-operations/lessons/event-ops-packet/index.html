Lesson 4 · ~40 min

Compile the Event Operations Packet

Package all documents into a single ops folder ready for event day.

Game scenario: Saturday morning: volunteers need one link with everything to run Community Cup without asking you basic questions.

Steps

  1. Create the master folder

    community-cup-ops/ containing: bracket.png, schedule.pdf, run-of-show.pdf, staff-roles.pdf, discord-plan.pdf, and emergency-contacts.txt.

  2. Write the quick-start README

    Top of README: event time, stream URL, ops lead phone/Discord, and 'Start here' checklist (5 items max for opening the event).

  3. Dry run checklist

    List 10 items to verify 1 hour before go-live: stream test, bot permissions, bracket link live, refs in voice channel, check-in open.

  4. Post-event template

    Include a results recap template: winner, final score, MVP nomination, link to VOD timestamp. Ops lead fills this in after the final.

Your goal

Event Operations Packet

Complete ops folder with README, dry-run checklist, and post-event template.

Format: Folder (PDF/docs) + shareable link

Success criteria

Check each item when your deliverable meets the standard.

Tools

  • Google Drive or Notion
  • PDF export
  • Discord
