Lesson 3 · ~30 min

Assign Staff and Discord Channels

Define roles and set up communication channels for event day.

Game scenario: You have 6 volunteers: 2 refs, 1 broadcast tech, 1 ops lead (you), 1 community mod, and 1 backup ref.

Steps

  1. Write RACI-style roles

    For each function—match check-in, dispute resolution, stream start, results posting—assign one Responsible person and one Backup.

  2. Design Discord channels

    Create or document channels: #announcements (read-only), #team-check-in, #match-chat (refs only during disputes), #broadcast-tech, #results. Set permissions per role.

  3. Draft event-day messages

    Pre-write: welcome message, rules summary, check-in template ('Team name / captain / ready status'), and forfeit warning.

  4. Run a tabletop walkthrough

    Simulate one dispute: team claims disconnect. Write exactly who responds, within what timeframe, and how the bracket updates.

Your goal

Staff role chart + Discord channel plan

Role assignments, channel list with permissions, and pre-written event messages.

Format: Doc with role table + channel map

Success criteria

Check each item when your deliverable meets the standard.
