Lesson 2 · ~35 min

Balance Comms and Game Audio

Route Discord, game, and microphone sources so casters and viewers hear the right mix.

Game scenario: Casters talk over Discord while the game runs on the stream PC. Viewers hear game + casters, but casters must not echo.

Steps

  1. Map your sources

    List every audio source: game capture, Discord voice, caster mic 1, caster mic 2, hype sting. Draw a signal-flow diagram on paper.

  2. Configure OBS inputs

    Add Application Audio Capture for the game. Add Audio Input Capture for each mic. Set Discord to a separate OBS source or use Voicemeeter for routing.

  3. Set monitor vs stream

    Casters need to hear each other and the game in headphones, but the stream mix should prioritize casters over in-game menu music. Adjust per-source volume: casters at -6 dB, game at -12 dB.

  4. Test for echo

    Record a 2-minute test stream. Play it back—if casters hear themselves delayed, disable 'Listen to this device' on monitoring paths.

Your goal

OBS audio routing diagram + test recording

Documented signal flow and a 2-minute test recording proving clean mix.

Format: Diagram (photo/PDF) + MP4 or screenshot of OBS mixer

Success criteria

Check each item when your deliverable meets the standard.

Tools

  • OBS Studio
  • Discord
  • Voicemeeter (optional)
  • Headphones
