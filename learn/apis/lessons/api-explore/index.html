Explore a Public API

Read docs and test endpoints.

Game scenario: Use a free gaming API (e.g. RAWG, tracker.gg docs, or mock JSON).

Steps

  1. Pick API

    Find free tier with player or game stats.

  2. Postman test

    GET request, inspect JSON response.

  3. Document fields

    List 5 fields you'll use (name, rank, wins, etc.).

  4. Note auth

    API key header if required—never commit keys.
