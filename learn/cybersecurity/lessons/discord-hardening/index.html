Lesson 2 · ~35 min

Harden Discord Server

Apply security settings and role permissions.

Game scenario: Admin bot was compromised via excessive permissions.

Steps

  1. Audit roles

    List every role with ADMIN, MANAGE SERVER, or WEBHOOK permissions.

  2. Principle of least privilege

    Remove admin from bots that don't need it.

  3. Enable 2FA requirement

    Moderators must enable 2FA (document steps).

  4. Webhook audit

    List all webhooks—delete unused.

Your goal

Discord audit log

Before/after permission changes.

Format: Doc + screenshots
