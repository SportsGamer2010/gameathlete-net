Lesson 3 · ~40 min

Create a Stream Overlay

Design a lower-third overlay casters can use during live matches.

Game scenario: Your broadcast team streams on Twitch. They need a lower-third that shows team names and current series score.

Steps

  1. Design the lower third

    Create a bar across the bottom 15% of a 1920×1080 canvas. Use semi-transparent dark fill (70% opacity) so gameplay remains visible underneath.

  2. Add score slots

    Leave editable text areas for Team A score, Team B score, and series format (e.g. 'Game 2 — Bo3'). Use your league brand colors for accent lines.

  3. Plan for OBS

    Export as PNG with transparency. In OBS, add as an Image source above the game capture. Test that text areas are not covered by safe zones on mobile Twitch previews.

  4. Write a usage note

    Document how to update scores between games—either edit the PNG or use OBS text sources on top of your bar graphic.

Your goal

Broadcast lower-third overlay

Transparent PNG overlay with team name and score placeholders.

Format: PNG (1920×1080, transparent)

Success criteria

Check each item when your deliverable meets the standard.

Tools

  • Canva or GIMP
  • OBS (for testing)
  • PNG export
